# Wochenessensplan

Einfache Web-App für unseren Familien-Essensplan (2 Erwachsene, 1 Kleinkind), optimiert fürs iPhone.

- **Plan**: Gerichte für Mo–So auswählen oder per 🎲 zufällig vorschlagen lassen
- **Einkauf**: Zutaten werden zusammengerechnet und nach der Gangreihenfolge im Aldi sortiert; beim Einkaufen antippen zum Abhaken
- **Rezepte**: Rezepte mit Zutaten, Mengen und Kategorie anlegen und bearbeiten
- **Mehr**: Gangreihenfolge anpassen, Daten exportieren/importieren

Die Daten werden nur lokal im Browser des jeweiligen Geräts gespeichert (`localStorage`).

## Aufs iPhone

Seite in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“. Dann startet sie wie eine App und funktioniert auch offline.

## Technik

Reines HTML, CSS und JavaScript – kein Build-Schritt. Gehostet über GitHub Pages.
